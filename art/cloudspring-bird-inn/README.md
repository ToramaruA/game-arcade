# 雲海温泉と渡り鳥の宿：絵素材

審査 #101 design revision 1 の合格後に作成。原寸PNG、画像内の文字なし。キャラ表を最初に生成し、残る5枚は同表を参照して生成。

- `sheet-koko.png`：ココの正面・横・背面・表情を統一するキャラ表。
- `char-koko-welcome.png`：ココ全身の歓迎ポーズ。案内・精算画面用。
- `char-koko-side.png`：ココ全身の右向き歩行ポーズ。宿の案内用。
- `title-cloudspring.png`：雲海の温泉宿の一枚絵。タイトル・共有画像の下絵。
- `bg-cloudsea.png`：雲海と遠景の浮島。盤面の背後に置く背景。
- `prop-bath.png`：浴槽の単体絵。設備素材・見た目の参照。

単体キャラと小物は白背景。実装時に切り抜く。文字・温度・風向・UIはプログラムで描く。タイトル絵は世界観の例であり、実際の施設配置・客種・判定は承認済み設計を優先する。浴槽の湯気は静止画の表現なので、実装の給湯量・風向に応じた蒸気表現に合わせて調整する。ゲーム盤面の主色は薄桃・黄緑・クリーム、ターコイズは背景遠景のみに使う。
