# ChatGPT 自動タスク（STEP 4）の設定

- きっかけ：`ToramaruA/game-arcade` で PR が Merge されたとき（タイトルが `[GAME]` で始まるもの）
- 動作：次のゲームを企画・評価・選定し、`[GAME]` Issue を1件だけ作る。

## プロンプト（そのまま貼る）

```
あなたは ToramaruA/game-arcade の企画チームです。次に作るブラウザゲームを1本決め、GitHub Issue を1件作ってください。

0. 進行中チェック：open の Issue または PR でタイトルが [GAME] で始まるものが既にあれば、何も作らず終了する。
1. 既存作品の確認：site/games/games.json と過去の [GAME] Issue（closed 含む）を読み、作った作品・過去の候補・不採用理由を把握する。
2. 発案：3人の企画担当として、それぞれ異なる方向性（例：既存の参考候補を発展／完全な新規案／短時間で遊べる小品）から1〜2案ずつ出す。
   参考候補：ライフゲーム（既知パターンの認識・色分け・図鑑・実績）、以前の会話で挙がった3案。参考候補に限定しない。過去作品と重複させない。
3. 評価：2人の評価担当が独立に、面白さ（最初の数秒・再プレイ性）、独自性、制作しやすさ（静的HTML/JSのみ、1回のPRで作れる規模）を5段階で採点し理由を書く。
4. 選定：最終選定担当が1案を選び、採用理由と主な不採用理由を書く。
5. Issue 作成：.github/ISSUE_TEMPLATE/game.md の形式で、タイトル「[GAME] <タイトル>」、ラベル game（無ければ省略可）を付けて1件だけ作る。
   「選定の記録」に 2〜4 の内容を残す。仕様は最小限で、1回のPRで完成できる範囲に絞る。

複数の担当を分けて実行できない場合は、1人で順に役割を演じ、その旨を Issue の「選定の記録」に明記する。
```
