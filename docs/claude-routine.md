# Claude Code 自動実行（STEP 3）の設定

https://claude.ai/code/routines で自動実行を作る（作成済みなら「編集」で以下に合わせる）。

- リポジトリ：`ToramaruA/game-arcade`
- トリガー1：GitHub イベント → Issue: オープン → フィルター「タイトル」「次で始まる」`[GAME]`（新作）
- トリガー2：GitHub イベント → Issue: オープン → フィルター「タイトル」「次で始まる」`[FIX]`（修正依頼）
- コネクタ：なし

## プロンプト（そのまま貼る）

```
きっかけになった Issue を読み、このリポジトリの CLAUDE.md に従って対応してください。

- タイトルが [GAME] で始まる：「[GAME] Issue を受けたときの手順」でゲームを1本作り、PR を出す。
- タイトルが [FIX] で始まる：「[FIX] Issue を受けたときの手順」で対象ゲームを直す。
- どちらでもなければ、何もせず終了する。
- 同じ Issue を参照する open な PR が既にあれば、新しく作らず Issue にコメントして終了する（[FIX] で既存のゲーム PR に追記する場合を除く）。
- main へは push しない。PR の Merge もしない。
- 途中で止まる場合は、理由を Issue にコメントしてから終了する。
```

## 修正依頼の出し方
次のどれかで `[FIX]` Issue を作るだけでよい。
- ChatGPT に頼む：「game-arcade に修正Issueを作って。半分くださいの切る線を太くしてほしい」
- GitHub アプリ：Issues → New → 「修正依頼」を選び、タイトルを書いて送信
- タイトル例：`[FIX] 半分ください：切る線をもっと太く`
