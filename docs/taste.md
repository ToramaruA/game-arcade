# 好みメモ（企画と見た目の基準）

ChatGPT（企画）と Claude Code（制作）の両方が毎回読む。オーナーが遊んだ感想はいちばん下に追記していく。

## いちばん大事なこと
- **ぱっと見で面白そう**：スクリーンショット1枚で「何これ、やってみたい」と思えること。
- **他人にも見せたくなる体験**：結果や展開を人に話したくなる・共有したくなること。

## 気に入っていた企画（チャットで出た案）
| 案 | 内容 | 良かったところ |
| --- | --- | --- |
| 人類最後の60秒 | 宇宙船で重大事故。60秒の選択で生存者の数が変わり、結果を共有できる | 緊迫した設定、選択が結果に直結、共有したくなる結末 |
| 未来の考古学者 | 持ち物を3つ選ぶと、数千年後の考古学者が持ち主の人生を推理する | 自分の選択が意外な解釈になって返ってくる |
| あなたが作った国の100年後 | 国の制度を3つ決めると、100年間の変化がシミュレーションされる | 少ない入力から予想外の結末が生まれる |

共通点：はっきりした**設定・世界観**があり、**少ない選択が大きな・意外な結果**になって返ってくる。

## 参考にしたい「当たり方」
真似をするのではなく、**なぜ当たったか**を企画の物差しにする。（2026-10-31 調べ。出典は末尾）

### 80億分の1（2026年10月、ブラウザの人生シミュレーター）
- 中身：生まれる国・家庭・性別はランダムで選べない（国連・WHO・世界銀行などの統計に基づく）。1年ごとに選択を重ねて一生を送る。勝ち負けやゴールはない。登録不要・無料、1分で1年ほどと短い。個人開発者が生成AI（Claude）で約4時間で作ったとされる。
- 当たった理由（オーナーの見立て＋報道）：
  - **シンプル**：すぐ始められ、操作は「選ぶ」だけ、1回が短い。
  - **繰り返し遊びたくなる**：生まれが毎回ちがい、「次はどんな人生か」が気になる。
  - **プレイごとに物語ができる**：同じ生まれでも結末が大きく違い、遊んだ人それぞれに一生分のストーリーが残る。
  - **それを共有したくなる**：「〇〇の国に生まれて何歳で大往生した」のような結果の投稿と比べ合いで広がった。「泣いた」「考えさせられる」という感情の動きも投稿の理由になった。
  - **現実とつながる題材**：統計に基づくリアルさが「国ガチャ・親ガチャ」の話題と結びつき、遊びの外でも語られた。

### Wordle（言葉当てパズル）
- 1日1問で、みんなが同じ問題を解く。
- **答えを明かさずに結果だけ見せられる絵文字の格子**を共有でき、それが広がるきっかけになった（作者も「他人の楽しみを壊さず自慢できる」ことを理由に挙げている）。
- 学ぶこと：共有文は**ネタバレせずに自分の物語や腕前が伝わる形**にする。

### Reigns（左右スワイプで王国を治める）
- 操作は左右に振るだけ。それでも選択が積み重なって、毎回ちがう王の一代記が生まれる。
- 学ぶこと：**入力は極端にシンプルでも、結果の物語は豊かにできる**。一方で、何度か死ぬと新しい展開がなく飽きるという批判もある → 繰り返すほど新しい出来事に出会える量と仕組みが要る。

### 企画で自分に問うこと
- 1回の結果を**一文の物語**にできるか（例：「居住環を捨てて、18人だけが脱出艇で帰った」）。その一文は遊ぶたびに変わるか。
- 毎回変わる理由（偶然・組み合わせ・選択の積み重ね）が**ルールの中に**あるか。正解を一度解いたら終わり、になっていないか。
- 結果画面と共有文が、点数だけでなく**その物語を見せる**形か。ネタバレせずに共有できるか。
- 始めるまでが一瞬で、1回が短いか。
- ルールを足して深くするより、**少ない要素の組み合わせ**で幅を出しているか。何回か遊んでも新しい出来事に出会えるか。
- 感情が動く瞬間（泣ける・笑える・ゾッとする）があるか。

## 見た目の好み（チャットで見たイメージ画像の印象）
- 比較的**レトロ**なものが多い（強制ではない）。例：
  - 宇宙船のコックピット：暗い背景、緑に光るブラウン管モニター、計器、ドット絵
  - 博物館風：濃紺と金、展示ケース、古い地図や遺物
  - 箱庭シミュレーション：斜め見下ろしの街、統計パネルやグラフが並ぶ画面
- 画面に**情報量と“世界”がある**。主役の絵、パネル、数値、ラベルが詰まっていて、1枚で設定が伝わる。
- 逆に、**淡い単色背景に図形とボタンだけ**の、すっきりしすぎた画面は物足りない。

## 微妙だったもの
- 「半分ください」「あと1人、乗れます」：遊びとしては成立しているが、題材が日常の小ネタで、見た目もパステル調でフラット。ぱっと見の驚きや世界観がない。
