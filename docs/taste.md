# 好みメモ（企画と見た目の基準）

ChatGPT（企画）と Claude Code（制作）の両方が毎回読む。オーナーが遊んだ感想はいちばん下に追記していく。

## いちばん大事なこと
- **ある程度中身が凝っていないと面白くならない**（オーナー、2026-11-07）。見た目や一発のアイデアだけでは続かない。一流のゲームプロデューサーとして、遊びの核・判断の深さ・中身の量・手触りまで考える。
- **ぱっと見で面白そう**：スクリーンショット1枚で「何これ、やってみたい」と思えること。
- **他人にも見せたくなる体験**：結果や展開を人に話したくなる・共有したくなること。

共通点：はっきりした**設定・世界観**があり、**少ない選択が大きな・意外な結果**になって返ってくる。

## 参考にしたい「当たり方」
真似をするのではなく、**なぜ当たったか**を企画の物差しにする。（2026-10-31 調べ。出典は末尾）

### 80億分の1（2026年10月、ブラウザの人生シミュレーター）
- 中身：生まれる国・家庭・性別はランダムで選べない（国連・WHO・世界銀行などの統計に基づく）。1年ごとに選択を重ねて一生を送る。勝ち負けやゴールはない。登録不要・無料、1分で1年ほどと短い。個人開発者が生成AI（Claude）で約4時間で作ったとされる。
- 当たった理由（オーナーの見立て＋報道）：
  - **シンプル**：すぐ始められ、操作は「選ぶ」だけ、1回が短い。
  - **繰り返し遊びたくなる**：生まれが毎回ちがい、「次はどんな人生か」が気になる。
  - **プレイごとに物語ができる**：同じ生まれでも結末が大きく違い、遊んだ人それぞれに一生分のストーリーが残る。
  - **それを共有したくなる**：「〇〇の国に生まれて何歳で大往生した」のような結果の投稿と比べ合いで広がった。「泣いた」「考えさせられる」という感情の動きも投稿の理由になった。
  - **現実とつながる題材**：統計に基づくリアルさが「国ガチャ・親ガチャ」の話題と結びつき、遊びの外でも語られた。

### ニンニクマシマシ（2026年10月、ブラウザのホラーゲーム）
- 中身：ラーメン店で、言葉を組み合わせて自由に注文する。注文できるのは100種類で、店にないものを頼むと断られる。トッピングの量や「マシ」の回数で出てくる一杯が変わる。
- 当たった理由（オーナーの見立て＋報道）：
  - **シンプル**：やることは「言葉を組み合わせて頼む」だけ。
  - **コンプリートしたくなる**：100種類という明確な数があり、「次は何が出るか」を試したくなる。全100種類を達成した人の投稿が話題になった。
  - **予想を裏切る結果**：組み合わせ次第で、ふつうの一杯からホラーな展開まで変わる。何が起きるかは試すまで分からない。
  - **共有したくなる**：「〇〇を完食しました。総摂取カロリー：9,200kcal」のように、結果を数字つきで投稿できる。答えを伏せ字にして投稿する人もいた（ネタバレせずに自慢できる）。
- 学ぶこと：**組み合わせで結果が変わる仕組み＋集める楽しさ（図鑑・コンプリート率）＋意外な結果**は、シンプルでも繰り返し遊ばれる。結果の数が多いほど1つずつの絵が必要になるが、部品の組み合わせで描けば数を増やせる。
- **いちばん大事な点（オーナー、2026-11-05〜07）**：面白さの中心は、**文字を組み合わせて自分で言葉を作り、それが「あるかどうか」を探す**こと。思いついた言葉が通ったときの「これあるの！」「あるんかい！」という驚きを、作り手が仕込める。
  - **用意された選択肢（ダイヤル）から選ぶだけ**、**用意された単語カードを組み合わせるだけ**では、この面白さは出なかった（「空が壊れるまで」のダイヤル版・単語カード版の両方で確認）。単語カードは選択肢が多いのに、自分で考えた感じがしない。
  - 一方で、何でも自由に打てると広すぎて想像しづらい。**部品は少なく単純（文字など）、作れる言葉は多い**くらいがよい。
  - 作れそうな言葉の言い方の揺れを広く受け止め、作り手が「まさかこれも？」という言葉やネタまで仕込む。

### Wordle（言葉当てパズル）
- 1日1問で、みんなが同じ問題を解く。
- **答えを明かさずに結果だけ見せられる絵文字の格子**を共有でき、それが広がるきっかけになった（作者も「他人の楽しみを壊さず自慢できる」ことを理由に挙げている）。
- 学ぶこと：ネタバレせずに自分の結果や腕前を見せられる共有の形は、広がるきっかけになりうる。

### Reigns（左右スワイプで王国を治める）
- 操作は左右に振るだけ。それでも選択が積み重なって、毎回ちがう王の一代記が生まれる。
- 学ぶこと：**入力は極端にシンプルでも、結果の物語は豊かにできる**。一方で、何度か死ぬと新しい展開がなく飽きるという批判もある → 繰り返すほど新しい出来事に出会える量と仕組みが要る。

### 企画のヒント（必須条件ではない。題材に合うものだけ取り入れる）
- 遊んだ結果が、人に話したくなる**その人だけの展開**になっているか（一文にまとめる必要はない）。
- 遊ぶたびに展開が変わる理由（偶然・組み合わせ・選択の積み重ね）があるか。
- 結果画面や共有文で、その展開が伝わるか。
- 遊ぶ長さは題材に合っているか（短ければ良いわけではない。物足りなさが残るほど短くしない）。
- ルールを足すより、少ない要素の組み合わせで幅を出せないか。何回か遊んでも新しい出来事に出会えるか。
- 感情が動く瞬間（泣ける・笑える・ゾッとする）があるか。

## 次の企画への要望（オーナーから。使ったらこの節を消す）
- 次の企画では、3人の企画担当のうち1人は「ニンニクマシマシ」の当たり方（**文字などの単純な部品を組み合わせて自分で言葉を作り、あるかどうかを探す**・集めたくなる多数の結果・意外な結果やネタ・数字つきで共有できる結末）を参考にした案を出す。選択肢から選ぶだけ、用意された単語を組み合わせるだけの形にしない。**題材や仕組みをそのまま真似しない**（ラーメン店・注文ゲームにしない）。当たった理由だけを、別の題材と世界観に移す。

## いろいろ試す（オーナー、2026-11-07）
- AIで作る良さは、**いろいろなアイデアをすぐ試せること**。同じ路線ばかりにせず、ジャンルも画風も毎回変えて試す。
- これまでレトロな画面が続いたので、**レトロ以外の画風も積極的に**（かわいい3D、パステルの絵本調、水彩、切り絵、ネオンなど）。「淡い単色背景に図形とボタンだけ」の地味さは引き続き避けるが、かわいい・きれいな画面は歓迎。
- 試してみたい案の例：**きれいでかわいい3Dの小さな世界をただ歩く。BGMが流れていて、何かを集められる**（散歩・雰囲気ゲー）。勝ち負けより、歩いているだけで気持ちいいこと、つい全部集めたくなることが中心。

## 見た目の好み（チャットで見たイメージ画像の印象）
- 比較的**レトロ**なものが多かった（強制ではない。最近はレトロが続いたので、ほかの画風も試す）。例：
  - 宇宙船のコックピット：暗い背景、緑に光るブラウン管モニター、計器、ドット絵
  - 博物館風：濃紺と金、展示ケース、古い地図や遺物
  - 箱庭シミュレーション：斜め見下ろしの街、統計パネルやグラフが並ぶ画面
- 画面に**情報量と“世界”がある**。主役の絵、パネル、数値、ラベルが詰まっていて、1枚で設定が伝わる。
- 逆に、**淡い単色背景に図形とボタンだけ**の、すっきりしすぎた画面は物足りない。

## 微妙だったもの
- 「半分ください」「あと1人、乗れます」：遊びとしては成立しているが、題材が日常の小ネタで、見た目もパステル調でフラット。ぱっと見の驚きや世界観がない。
- 「切り離せ、最後の一隻」（2026-11-01、公開せず終了）：見た目と設定は良かったが、**遊びとして面白くなかった**。
  - 事故の順番・場所が毎回同じで、最善の手順がほぼ1つに決まる。1回解いたら終わり。
  - 毎回「逃がす→切る」の繰り返しで、頭を使う悩ましい選択がない。
  - 結果がいつも似ていて、人に話したくなる展開が生まれない。
  - 修正（説明・手引き・表示の改善）では直らなかった。**面白さの核はルールで決まる**ので、企画と詳細設計の段階で「何を悩むのか」「遊ぶたびに何が変わるのか」を具体的に詰める。
